多源研报与文案生成 Agent

多源研报与文案生成 Agent 录屏：从抓取研报到生成多渠道文案的完整流程。

项目职责
需求梳理 / 工作流设计
核心技术
OpenClaw / 大模型文案生成
主要成果
日均处理 20+ 研报

项目背景

研究报告与行业研报来源分散、格式不一，运营与投研团队需要反复「下载–阅读–摘录–改写」，不仅耗时，还难以沉淀为可检索的结构化资产。希望用 OpenClaw 的 Skills 将「信息获取 → 结构化整理 → 多渠道文案生成」串成标准工作流，减少重复劳动。

方案设计

  • 多源抓取： 基于 OpenClaw 配置订阅源与爬取策略，自动从公开研报网站、团队共享盘与内部知识库收集最新内容。
  • 结构化摘要： 使用大模型将长文拆解为「结论 / 逻辑链路 / 关键数据」三层结构，输出统一模版的结构化摘要，便于检索与复用。
  • 多渠道文案生成： 针对邮件、社交媒体、内部周报等不同发布场景设计文案模版，一键生成不同语气与长度的版本，并自动落库归档。

效果与价值

  • 效率提升： 单篇研报从「下载 + 阅读 + 摘录 + 改写」约 30–40 分钟，缩短到 5 分钟内完成审阅与定稿。
  • 知识沉淀： 所有摘要与文案按「赛道 / 机构 / 时间」自动归档，后续选题与复盘可以直接在库内检索引用。
  • 沟通体验： 不同渠道的文案风格统一又不雷同，使关键结论更容易被业务与管理层快速理解与采纳。
