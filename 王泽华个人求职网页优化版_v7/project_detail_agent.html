招投标自动化

政企招投标自动化清标与审计系统

提示：滚轮缩放，按住拖动可查看细节。

项目职责
产品设计 / 工作流编排
核心技术
Dify / DeepSeek·Qwen / RAG
主要成果
人工审计用时15分钟缩短到45s

项目背景

政企招投标清标与审计依赖大量人工比对条款、计算偏差，耗时长且易出错。需要将招标文件、投标文件与标准规范进行语义拆解与硬性指标校验，并输出结构化审计结果。

技术架构

  • Dify 工作流编排： 使用 Dify 搭建核心清标与审计流水线，串联文档解析、语义理解与结果汇总。
  • 多模型分工： 利用 Qwen2.5 进行招标/投标文本的语义拆解与条款抽取，DeepSeek V3 负责标准计算与合规判断。
  • RAG 优化： 将采购的服务器白皮书、历史标书纳入知识库，通过 RAG 提升检索与引用准确性，减少幻觉。

工程亮点

针对模型在数值计算上的幻觉问题，使用 Python 脚本 执行硬性指标校验（如价格、工期、资质条款），将 LLM 输出与规则引擎结合，确保审计结果可追溯、可复验。
