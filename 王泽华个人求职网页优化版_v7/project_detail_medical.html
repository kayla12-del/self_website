医疗影像数字化

中医舌下络脉影像标准化与智能分割

项目职责
项目负责人 / 产品实习
核心技术
SAM 2 / Python / CV
主要成果
Dice系数提升 36%

项目背景

传统中医诊断依赖医生主观经验，在舌下络脉分析中，由于影像对比度低、光照复杂，传统的标注数据可用率仅为 44.1%，严重阻碍了算法模型的迭代。

核心方案

  • 大模型调研： 引入 Meta 最新的 SAM 2 模型，通过零样本（Zero-shot）能力解决低对比度下的边界模糊问题。
  • SOP 体系建立： 协调中医临床专家与算法团队，制定《中医舌下络脉标注标准约束文档》，将数据可用率从 44% 提升至 92%。
  • 工程链路优化： 开发自动化预处理脚本，减少人工预筛选成本 60% 以上。
