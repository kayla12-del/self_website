医疗影像数字化

中医舌下络脉影像标准化与智能分割

项目职责
项目负责人
核心技术
SAM 2 / Python / CV
主要成果
Dice系数提升 36.12%

项目背景与痛点洞察

初期瓶颈： 项目前期，医疗团队已经积累了大量舌诊 RGB 影像，但在多轮自动分割与量化尝试中，模型精度始终无法达到临床要求，专家一度认为问题出在 RGB 色域表达力不足，希望投入资源研发全新的色彩表征算法。

需求分析： 接手后没有直接投入算法研究，而是先对首批数据做基准测试，发现影响上限的关键并非模型结构，而是“医生经验标准”与“视觉工程标准”之间存在明显语义断层。

关键发现： 由于缺乏统一的标注协议，首批标注数据存在大量语义偏差与噪声，可用率仅为 44.1%；在这样的数据前提下，任何算法调参都只能在“脏数据天花板”下内卷。

核心方案：从算法驱动到数据治理驱动

作为项目负责人，我主导将路线从单一“算法研发”调整为“AI 辅助标注 + 数据质量闭环平台”的建设：

  • 标准重构： 通过深入了解医生团队的标注流程，将医生的主观视觉经验拆解为可量化的视觉工程指标，联合专家共建统一的舌下络脉标注协议与质检规范。
  • SAM 2 驱动的AI辅助标注系统：
    • 冷启动阶段：精选高质量样本，对 SAM 2 进行少量微调，使其适配舌下络脉场景。
    • 预标注与回流：由模型给出预标注结果，在可视化平台中由不同权限层级医生进行核验与微调，大幅减少重复描边工作。
    • 主动学习：高置信度样本自动进入训练集，对于Badcase进行定向增强与回标，持续抬升模型上限。

业务价值与成果

  • 数据质量提升： 通过标准重构 + AI辅助标注系统，将影像数据可用率从 44.1% 提升到 92%，为后续深度学习任务提供了可闭环的数据底座。
  • 效率提升： 在统一标注标准和预标注机制下，完整标注流水线效率提升约 60%，医生从“画轮廓”转向“做决策”。
  • 算法效果拉升： 在高质量数据集支撑下，舌下络脉量化分析模型的核心评价指标（如 Dice 系数）相较初始版本实现 36.12% 的断层式提升，从“实验室 Demo”真正跨过临床可用红线。
