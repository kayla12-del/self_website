产品思考与对比

OpenClaw：从工具到「私人贾维斯」

OpenClaw 是一款开源、自托管的个人 Agent 平台，直接运行在本地电脑、NAS 或云服务器上，并通过 Telegram、WhatsApp 等日常通讯软件远程操控整个操作系统；从一个周末兴趣项目起步，在 GitHub 上迅速拿下 25 万+ Stars，由 PSPDFKit 创始人 Peter Steinberger 发起，技术取向和对隐私的重视非常鲜明。

它通过内置工具包和 Shell 访问能力操作文件系统、执行命令行、驱动浏览器自动化，再结合挂载到多种 IM 的「网关」、基于本地 Markdown 的长期记忆和「Heartbeat」心跳引擎，让 Agent 能够既记住你的偏好，又主动发起对话，逐步长成一个 24 小时守候、懂你习惯、能直接拿结果的「角色」。

这背后的产品启示是：当 AI 可以直接控制 OS 时，「对话即控制」重构了人机交互，我们不再需要学习复杂应用，而是学习如何给自己的代理下指令；与此同时，在这种权限等级下，开源和自托管不只是卖点，而是建立信任的最后堡垒，也是 OpenClaw 作为「私人贾维斯」最坚实的底线。

Figma AI：嵌入工作流的设计助手

观察 Figma AI，我更关心的是它如何作为「长在画布里的助理员工」改变设计师的工作边界：从自然语言生成布局（Prompt-to-UI）、智能重命名图层，到识别页面结构后一键补齐原型交互，它不是一个独立工具，而是直接嵌在主战场里的生产力层。

一个明显的启示是：规范是 AI 自动化的燃料。企业的 Design System 和组件库越完备，Figma AI 调用这些资产时就越精准、越贴近真实交付；Motiff 等竞品若想在本土场景突围，也需要在中文排版、行业模板等「结构化规范」上做更深打磨。

更长期的变化在于角色迁移——UI 设计从「操纵像素」转向「管理意图」，审美判断、交互逻辑与业务理解会成为新的护城河。Figma AI 证明了：只有深度嵌入垂直工作流（如 UI/UX 交付），AI 才可能从酷炫 Demo 变成真正稳定的「印钞机」。

AI 搜索：Perplexity 的产品位势

Perplexity 相对 Google / ChatGPT 的差异：它并不是简单的搜索，而是在降低信息不确定性（验证性）和提高信息综合效率（合成）上重新做了产品设计。

1）相对 Google：Google 的核心是索引，用户要自己阅读和判断；Perplexity 把价值放在「综合」，用结构化回答和引用链路，直接给出可验证的结论，减少「信息搬运」的认知负担。

2）相对 ChatGPT：早期 ChatGPT 容易给出「看起来对」但无法验证的答案。Perplexity 通过强制引用、答案拆分和来源展示，把「可验证性」放在产品一层，这对有研究 / 工作背景的用户更友好。

在此基础上，我也思考它的护城河和商业化：一方面通过模型中立 + Pages / Collections 等垂直工作流，争取「知识工作操作系统」的位置；另一方面在变现上更偏向意图原生广告和高价值动作分成，而不是简单贴片广告，避免破坏搜索体验。
